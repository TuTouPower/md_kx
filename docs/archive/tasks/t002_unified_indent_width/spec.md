# Task spec

## 背景

mdformat 遵循 CommonMark「marker 对齐内容」语义，不强制统一缩进。同一文档内 2/3/4/5/6 空格混用的嵌套列表缩进被判定全部合法后不改动，导致文档缩进风格混乱。用户提出二次开发需求：提供缩进宽度配置项，让嵌套列表缩进统一为指定宽度（本项目统一 4 空格）。

## 契约区

### 范围

- 新增配置项指定嵌套列表统一缩进宽度
- 设置后文档内所有嵌套列表缩进统一为该宽度
- 代码块（``` 围栏内）内容不被改动

### 非范围

- 不改变行内文本、标题、引用的缩进语义
- 不改变默认行为（未设置配置时输出与现有一致）

### 风险与回退

- 风险：强制统一缩进破坏 CommonMark「marker 对齐内容」语义，影响内容块（多行项、嵌套代码块）排版。
- 回退：AC-001 默认行为不变兜底；缩进统一只作用于嵌套列表 marker 层级，内容块缩进不强制改，涉及实现边界由 Step 1 spike 确认。
